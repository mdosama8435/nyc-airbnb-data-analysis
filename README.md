# NYC Airbnb Market Analysis 2019

An exploratory data analysis project investigating Airbnb listings across New York City using Python, Pandas, Jupyter Notebook, and Tableau.

## Project Overview

This project analyzes the 2019 NYC Airbnb dataset to explore listing distribution, pricing patterns, room types, host activity, and availability across different neighbourhoods and boroughs.

The objective is to transform raw listing data into meaningful insights through data cleaning, exploratory data analysis (EDA), and interactive data visualization.

## Objectives

- Clean and prepare the Airbnb dataset for analysis.
- Analyze listing prices and availability.
- Explore the distribution of listings by room type and neighbourhood.
- Compare listing patterns across NYC boroughs.
- Build a Tableau dashboard to communicate key findings.

## Tools & Technologies

- **Python** — data analysis
- **Pandas** — data cleaning and manipulation
- **Jupyter Notebook / Google Colab** — analysis workflow
- **Tableau** — interactive data visualization
- **CSV** — dataset format

## Key Findings

Based on the 2019 dataset:

- **48,895 listings** are included in the dataset.
- **37,457 hosts** are represented.
- **$152.72** is the average listed price.
- **$106** is the median listed price.
- **112.8 days** is the average availability per year.
- Manhattan and Brooklyn account for approximately **85.4% of listings**.
- Entire homes/apartments and private rooms account for approximately **97.6% of listings**.

These figures describe the dataset, not current Airbnb market conditions. Listed price does not necessarily represent realized revenue, and availability does not directly measure occupancy.

## Dataset

The project uses the **New York City Airbnb Open Data (2019)** dataset, containing listing, host, location, price, room type, review, and availability information.

## Limitations

- The analysis represents historical 2019 data.
- Listed prices should not be interpreted as actual booking revenue.
- Availability is not equivalent to occupancy.
- Review counts alone do not establish guest satisfaction.
